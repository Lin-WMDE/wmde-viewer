# Test images

`1315754.jpg` and `test_format.*` are sample files in each supported container.

`orientation_6.jpg`, `orientation_6.png` and `orientation_6_exif_thumb.jpg` test EXIF
orientation. Each stores two halves side by side, left and right, as the sensor saw them, with
EXIF Orientation 6 ("rotate 90 degrees clockwise to view"), so viewed correctly the left half
is on top. The JPEG covers the turbojpeg full decode and the DCT-scaled thumbnail, the PNG
(eXIf chunk) the zune decoder, and the third file carries an IFD1 thumbnail in other colours
than its main image, so the thumbnail test also tells which of the two it was given.

They are generated by `make_orientation_fixtures.py` (Pillow):

    python3 make_orientation_fixtures.py test_images
